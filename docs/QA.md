- 运行时校验覆盖八张生产地图路径、谜题依赖、危险解除引用、口令推导和所有交互点与导航网络的连接关系。

### 玩家 AI 评审

- 美术评审确认旧版最大问题为白盒块状地图、矩形角色和常驻调试标签；本轮均已替换。
- 探索评审提出全屏变形、自动路线穿越危险和谜题完成后世界不改变；本轮逐项修复。
- 关卡评审建议保留数据驱动谜题，同时为地图增加生产绘制层和与谜题 ID 相连的状态变化；本轮沿用同一 32 谜题数据，并增加 `background`、`disabledBy` 与逐关导航网络。
- 完整记录见 `docs/AI_PLAYER_REVIEW_01.md`。
- 第二轮美术复审结论：已达到“可对外展示、可完整试玩的视觉 Alpha”；正式生产版前仍需碰撞遮罩与前景遮挡两项 P0。

### 仍需真人试玩

- 八关首次游玩中的误点热点、可行走网络边缘和目标靠近距离。
- 单张高分辨率地图在低端集显、移动设备和弱网络下的加载与内存占用。
- 危险预警代价是否让自动路线足够可信，又没有替玩家完成观察与等待。

### 已知边界（0.9 当时状态）

- 地图目前是单层绘制，尚无树冠、屋檐、桥洞等前景遮罩和 Y 轴深度排序。
- 0.9 当时主角仍是单张基准图；此项已由 0.9.1 的正面/背面动作组部分解决，左右方向目前使用镜像。
- 环境与 UI 声音仍为 Web Audio 程序化原型。
- `npm test` 尚未配置；当前自动检查为 TypeScript、Vite 构建和运行时关卡校验。

## 2026-09-07 · 原型 0.4

### 已验证

- TypeScript 严格模式检查和 Vite 正式构建通过。
- 全新本地来源下可以从零开始，点击蓝色目标自动靠近并拾取小铲。
- 停转水轮不能徒手疏通；取得小铲后可完成清淤，显示三枚金色木销并记录数字 `3`。

- 浏览器运行时无控制台错误或警告。

### 仍需真人试玩

- 三声水轮敲击和三枚视觉木销是否足以让玩家自然理解数字 `3`。
- 程序化点击音、脚步音和警告音在普通耳机与笔记本扬声器上的舒适度。
- 风向教学信息是否应该保持更久，第一次吹回是否会被理解为教学而不是操作失败。
- 静音、单声道和重要声音字幕关闭三种组合的完整通关验证。
- 图案门锁的一次输入反馈是否比原来的文字标签更容易回忆，而不是更难辨认。

### 已知阶段限制

- 当前声音由 Web Audio 程序化合成，用于验证事件语义，不是最终音乐与音效资产。
- 野餐缺口与花田四段顺序谜题尚未实现，仍沿用 0.3 的直接交互。
- 区域环境声目前只有轻量春风和水声底层，尚未实现磨坊、河岸、花田与小屋的完整交叉淡化。
- 仍缺少真实设备和 5–10 名无说明玩家的量化试玩数据。
