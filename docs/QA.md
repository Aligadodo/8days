# 验收记录

## 2026-09-06 · 原型 0.3

地图与日志验收画面分别保存在 `docs/qa-preview-0.3-map.png` 和 `docs/qa-preview-0.3-journal.png`。

### 已验证

- TypeScript 严格模式检查和 Vite 正式构建通过。
- 主线金、工具蓝、小事绿、观察粉四类主动光边正常绘制。
- 点击蓝色工具目标可自动靠近并拾取小铲。
- 点击粉色蒲公英可自动靠近，写入自然图鉴并切换到完成态。
- 点击绿色路标可完成今日小事并解锁“认路的人”。
- 页面重新载入后，`1/5` 自然发现、`1/9` 成就和已完成路标任务仍然保留。
- 日志抽屉集中显示主线、三件小事、四条口令、五项发现、九项成就和总体百分比。
- 页面运行时无新增警告或错误；开发服务器缓存重启后模块状态正常。

### 仍需真人试玩

- 四种光边能否在不阅读设置图例的情况下被正确理解。
- 同屏 3–5 个光边目标是否恰当，是否需要降低远处目标亮度。
- 今日小事和自然观察是否能自然吸引玩家，而不是产生清单压力。
- 完整收集耗时能否稳定在 12–18 分钟。

### 已知阶段限制

- 新交互物仍使用程序化像素图形，没有独立精灵动画。
- 交互行为共享寻路、光边和持久化规则，但对象绘制尚未完全数据化。
- 暂无 NPC 委托、秘密点和成就外观奖励。

## 2026-09-06 · 原型 0.2

验收画面保存在 `docs/qa-preview-0.2.png`。

### 已验证

- TypeScript 严格模式检查和 Vite 正式构建通过。
- 浏览器热更新后页面能够正常进入关卡。
- 左键点击空地可触发路径计算并自动移动。
- 左键点击磨坊目标后，角色自动走近并记录数字 `3`，无需再按 E。
- 鼠标提示、目标高亮、路径点和落点反馈已接入。
- 右键取消、键盘接管与暂停清理按键状态已接入。
- 出生镜头完整显示主角、水磨坊、工具箱闪光、河岸和石桥方向。
- 小屏幕鼠标环境不再显示触屏方向键；粗指针设备仍保留触控按钮。

### 仍需真人试玩

- 按住左键连续跟随的转向频率是否自然。
- 32 像素寻路网格在建筑边缘是否产生可感知的折线。
- 点击目标的 48 像素热区是否过大或过小。
- 自动移动进入危险区时，玩家是否有足够时间右键取消或用键盘接管。

### 已知阶段限制

- 程序化建筑和角色仍是原型图形，清晰度提升不等于最终像素资产质量。
- 寻路只理解静态矩形碰撞；暂未加入局部避让、移动 NPC 和路径重算动画。

## 2026-09-06 · 原型 0.1

验收画面保存在 `docs/qa-preview.png`，用于后续比较界面和响应式布局变化。

### 已验证

- TypeScript 严格模式检查通过。
- Vite 正式构建通过。
- 本地页面能够加载，浏览器控制台无错误或警告。
- 开始关卡后主界面正确出现。
- 背包可以打开和关闭，并在打开时暂停关卡。
- 道具、日志、存档和设置四个标签可以切换。
- 危险辅助设置能够写入浏览器状态。
- 快捷栏按五个固定位置显示已拥有和未发现物品。

### 需要玩家体验验证

- 连续移动的手感和镜头跟随速度。
- 阵风 1.35 秒预警是否足够公平。
- 坠枝 1.05 秒反应时间是否清晰。
- 从水磨坊到野餐地再到山顶小屋的路线是否容易理解。
- 口令线索永久保留是否降低了重复探索的挫败感。

### 已知阶段限制

- 当前场景和角色使用程序化像素图形，不是最终瓦片和精灵动画。
- 暂无音效、音乐、手柄支持和云存档。
- 只有春日花谷原型关卡。
- 触屏控件已提供，但仍需真机横屏测试。
