# 验收记录

## 2026-09-06 · 原型 0.1

验收画面保存在 `docs/qa-preview.png`，用于后续比较界面和响应式布局变化。

### 已验证

- TypeScript 严格模式检查通过。
- Vite 正式构建通过。
- 本地页面能够加载，浏览器控制台无错误或警告。
- 开始关卡后主界面正确出现。
- 背包可以打开和关闭，并在打开时暂停关卡。
- 道具、日志、存档和设置四个标签可以切换。
- 危险辅助设置能够写入浏览器状态。
- 快捷栏按五个固定位置显示已拥有和未发现物品。

### 需要玩家体验验证

- 连续移动的手感和镜头跟随速度。
- 阵风 1.35 秒预警是否足够公平。
- 坠枝 1.05 秒反应时间是否清晰。
- 从水磨坊到野餐地再到山顶小屋的路线是否容易理解。
- 口令线索永久保留是否降低了重复探索的挫败感。

### 已知阶段限制

- 当前场景和角色使用程序化像素图形，不是最终瓦片和精灵动画。
- 暂无音效、音乐、手柄支持和云存档。
- 只有春日花谷原型关卡。
- 触屏控件已提供，但仍需真机横屏测试。
