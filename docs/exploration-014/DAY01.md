# DAY01 · 夜灯杂货铺

## 体验目标与空间

主线暴雨通勤保持不变。玩家从便利店原生玻璃门进入售货区＋修补阅读角，补充约 5–8 分钟可选探索（设计估计，未做人类计时）。不进入咖啡店招牌下方，也不要求先解交通谜题。

户外门前站位世界 `(1370,350)`，新室内入口在底部双开玻璃门的连续地坪。底图原生 1672×941，标定时统一转换到 1600×900。屋顶、墙面、货架、桌椅、窗座、猫窝及门扇都不是地面；中部通道连接售货区和阅读角。返回口随时可用。

## 可玩内容

| 类型 | 对象与玩法 | 完成结果 |
| --- | --- | --- |
| 户外发现 | 屋檐下红色贩卖机 | 引导进入右侧真实玻璃门；不刷饮料 |
| 户外打卡 | 雨街暖灯倒影 | 安全位置摄影，不站到落物区 |
| 户外动物 | 店前小狗 | 3 点连续地砖巡游与亲近 |
| 环境故事 | 柜台红色手摇收音机 | 免费修补台、避雨空间的线索 |
| 环境证据 | 后墙伞图解 | 合伞→拧紧伞帽→慢慢撑开 |
| 工具收藏 | 工作台打开的工具盘 | 借细柄螺丝刀；工具盘保留 |
| 可见修复 | 台面蓝伞 | 读图＋借工具后修补，伞面展开，获纪念贴 |
| 明信片收藏 | 左下真实明信片架 | 取一张《夜灯与雨》，其余给后来者 |
| 自然收藏 | 阅读桌压花图鉴 | 获梧桐书签，原书仍留在桌上 |
| 室内打卡 | 圆窗雨线 | 「暴雨中的一盏灯」 |
| 室内动物 | 花猫 | 修补角 4 点巡游，不把猫窝当动物 |
| 环境故事 | 右墙老街照片 | 普通晴日的记忆，不藏主线密码 |

地方成就「今天，修好一件东西」验证图解、工具与修复三节点；「雨城的熟客」验证两张收藏、圆窗打卡和猫狗亲近。均只引用本包已有 ID，不改变主线口令、终点条件或危险设施。

## 风格与交互契约

- 底图及修伞完成态由内置 imagegen 生成，源图、完整提示词、裁片注册见 `design/exploration-014/day01/prompts.md`。
- 静物绑定实物形状；仅悬停描边，不额外生成大光圈、任务方牌或桌子图标。
- 门外、门内各存稳定返回站位。收藏 ID 唯一，重复进入不重复发奖；此去重逻辑由共享运行时实现。
- 桌面物件从可达操作侧读取；墙画允许隔着书柜远观，不把柜顶当站位。
- 修伞是本地可选工具链，不是题目弹窗。伞展开后碰撞仍由同一工作台负责，不修改通路。

## 已验证

作者脚本 `node design/exploration-014/day01/audit.mjs` 验证：

- 9 室内交互、3 户外发现、4 项收藏奖励（1 工具＋3 纪念/明信片/自然收藏）、2 成就。
- 室内出生点、出口、全部 9 操作站位，55 对精确寻路端点互通；不使用自动吸附掩盖失败。
- 户外入口和 3 发现站位在原始空 flags 状态全部可达。
- 8 个家具负样本：商品岛、修补台、阅读桌、明信片桌、分区货架、窗座、猫窝、玻璃门扇不可站立。
- 猫 4 段、狗 3 段巡游循环逐段可视通行，未穿家具或旧地图墙体。
- 曾发现阅读桌前小凳间的站位虽是地面却与主通道断连，已改为桌左侧真正可达的地毯站位，没有移除桌椅碰撞。
