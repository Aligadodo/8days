# DAY04 · 水声观测所

## 已实现的数据与素材

独立扩展包 `src/campaign/exploration/day04.ts`：1 张 1600×900 逻辑子地图、10 个室内交互、3 个户外交互、5 项可归档奖励（含 1 工具包）、2 项地方成就、1 只采用共享图集的巡游猫。原 DAY04 主线、危险与口令均未修改。

入口采用已经校准的东岸上层观瀑亭门洞 `(1224,149)`，站位 `(1229,187)`，`sharedTarget: exit`。由共享界面呈现进入/继续主线双选，不能把它当第二个重叠按钮。**进入需要先完成主线踏石通路 `lily-path`，不是初始可达；室内与主线完成状态无额外绑定。** 户外三项均在初始可达一侧。

空间分为西侧瀑景阅读室、东侧水务检修间和隔墙南侧通廊；敞开返回口在底部中央，任何收集/修复状态都不锁门。地图不是户外等比例放大图。

## 玩法和证据

室内完整链：阅读图解手册 → 观察主管压力表确认供水正常 → 借用工具台的盘根绳/短扳手 → 修复记录器右侧小接头 → 留存今日连续记录纸。检查表和借工具允许交换顺序，但修复必须三项齐备。手册明确工具、目标和操作原因，不依靠反复猜排列；不碰主管阀，不改变主线水位。修复后只在原画纸卷内注册替换连续波形纸面，避免把整部机器换成异风格图标。

其他内容不变成主线开锁前置：三枚标本提供安全观察；图卡、窗边拍照归入旅行册；水壶表现为给后来者留温暖；猫等待玩家靠近，不能捕捉或堵门。户外可以观察湿苔、听水轮慢拍、在台内侧拍双虹。收集奖励按稳定 ID 去重，公共画卡明确为拍摄复制；工具节点取得一段绳与原位借用凭记，维修时取扳手、用完放回。余绳、扳手、纸卷继续留在公共设施，避免文案说物品消失却仍留在背景。

地方成就：

- 今日水声保管员：完成有证据的检修链与纸卷留存。
- 把脚步放慢的人：水轮、湿苔、双虹、标本、小猫五项自然/生活观察。
