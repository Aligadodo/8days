# DAY06 — 避雨山舍：等一等，也是一条路线

## 交付与范围

实现 `src/campaign/exploration/day06.ts`，仅修改 DAY06 指定四处范围。未修改 registry、旧 world、共享引擎、主线、版本或全局文档，未提交 git，未访问 localhost:5173 或用户存档。接手时不存在 DAY06 扩展数据、资源与报告，故本次为首次实现。

精确内容：1 张可进入/返回的子地图，2 个活动区（左侧烘干区、右侧测绘/登记角），3 个户外发现，8 个室内交互（含 1 只共享图集猫），3 项去重归档奖励，1 处拍照打卡，2 项成就，1 条两步观察后确认的环境顺序链。无需工具，不修机器，不生成主线口令。

## 门与玩法流程

户外入口绑定原山间建筑正面两盏灯之间木门，源图门框 `(1275,181)–(1302,224)`；世界站位 `(1253,228)`，由既有“寺庙台阶”到达。它与茶亭热茶终点分离，不占用主线目标，故无需 sharedTarget。没有在茶亭假造门，也没有将营地帐篷当成山舍。

室内唯一门洞位于左下，可随时返回户外原站位。封闭雨窗不是入口。烘干区包含炉台、雨披、沥水靴盘、折巾凳；测绘角包含地形图桌与留舍登记桌。二者共用连续木地板，中间有宽通道。

可选路线：

1. 读北墙木牌。原画有真实“云 → 山 → 屋”形状与箭头，文字描述补足完整规则。
2. 点击雨窗（inspect）：密雨、低云遮山，没有雨停证据。
3. 点击地形图（inspect）：谷底汇水、裸露山脊缺少遮蔽；地图不是实时通行许可。
4. 回到登记簿确认（collect，requires 木牌；sequence 雨窗→地图）。按此顺序归档自己生活册中的“留舍等待”路线抄本。错误顺序可重看窗口与地图再确认，没有生命或资源惩罚。

选择留舍是本日的环境观察练习，不改变户外暴雨、危险、口令或主线推进。重复阅读 inspect 可重新构建顺序；其他 inspect 打断顺序时描述明确说明重看两处证据。

户外 3 项：桥头白花速写（nature 收藏）、营地煤油灯拍照（postcard 打卡）、木凳上旧登山包观察。真实煤油灯没有被误称为保温壶，主线新增保温壶独立保留。

室内 8 项：观察木牌、雨窗、地形图、留舍路线归档、折巾、蓝雨披、沥水盘、小猫亲近。

3 项奖励：雨中白花速写、有人留灯的营地照片、雨停前的留舍路线抄本。都是速写/照片/个人抄本，原实体留在支撑面，不存在拿走实体却留着原图的问题；无需 afterArt。ID 均 d06- 前缀，沿用共享收藏去重与存档。

2 项成就：等一等，也是一条路线（木牌、雨窗、地图、路线抄本）；把雨留在门边（靴盘、雨披、折巾、小猫）。条件均引用真实存在节点。
