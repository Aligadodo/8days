# DAY02 · 灯还亮着，也可以先休息

## 本关交付

一张实际可进入并返回的夜间子地图：左侧休息区、右侧旧档案工作台，共用无门禁宽地板。并非把整幅旧办公室放大，也不声称所有玻璃房间都可进入。

- 主图入口：西北侧原生会议室木门，门槛约世界 `(477,280)`，操作站位 `(490,315)`；这是玻璃前沿面向办公区的门，切场景前不跨会议室的阻挡多边形。与检修拉柄、维修暗门、消防门、楼梯终点独立。
- 外部 3 项：茶桌两只杯子、工位合影拍照、通道废稿背面的晚安涂鸦。
- 内部 9 项：休息留言板、小螺丝刀、修复旧收音机、照样折纸鹤、共享邮票拓印、窗边夜景打卡、温杯休息、铜铃、小猫亲近。
- 收藏/打卡：晚安涂鸦、工作之外的合影、小螺丝刀、夜班纸鹤、夜归邮戳拓印、灯火与归途照片。固定 ID 去重；不拿走别人的相框或整本共享册。
- 机制链：留言板明确解释 → 红工具箱借螺丝刀 → 断电拧紧外部旋钮 → 收音机亮灯 → 茶几照样折纸鹤。此链没有主线数字，不替代主线配电维修，不消耗工具。纸鹤样本和涂鸦废稿保留原地，玩家收录的是自己的折纸和临摹，不伪称背景实物消失。
- 两项地方成就：“修好一个小夜晚”“工作之外，也有生活”。
- 小猫：五个真实地板节点闭环巡游，先让猫自行接近；实体动物由共享猫图集提供，不把猫窝或文本冒充猫。
