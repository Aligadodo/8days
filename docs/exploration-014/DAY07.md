## 玩法与精确预算

- 一张可进入、原路返回的子地图：d07-room；原生 PNG 1672×941，世界坐标明确缩放至1600×900。
- 两个活动区：西侧双排长椅/茶柜/旅行卡的候车区；东侧三张失物桌/登记台/信号教学板的整理区。中央通道相连。
- 3个户外发现：窗下空椅、行李车包裹、盆栽雪松照片。
- 9个室内交互：图示、折伞、红手套、皮箱、登记簿、旅行卡、雪窗、信号示意板、猫。
- 4项归档奖励：站台雪松照片（nature）、核对存根抄件（keepsake）、雪夜旅行卡临摹（postcard）、暖窗候车照片（postcard）。2处打卡，2项成就，1只可见猫，5个巡游节点并核验闭环。
- 15个独立墙体/家具障碍；没有新增伤害或主线数字。

差异化操作链：读真实墙上“伞 → 手套 → 行李箱”图示 → 按顺序点击三张桌上的实物 → 点击右下登记簿确认 → 获得自己的存根抄件。雨伞收拢而墙图张开，要求识别物品类别；手套以拇指和编织纹辨认，皮箱以提手和搭扣辨认。未读图时登记锁定，错序清空观察历史并允许重试；图示与登记描述均给出全部证据。三灯示意板明确与行车信号/失物顺序无关。原失物不被移动，登记只抄写自己的存根；旅行卡临摹原样，照片只归档影像，因此没有可拿走实体残影，也不需要 afterArt。工具数0，非强制修复链。
