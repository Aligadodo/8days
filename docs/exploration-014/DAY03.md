# DAY 03 · 花匠的种子工房与附属温室

## 本轮范围与验收边界

实现文件：`src/campaign/exploration/day03.ts`，默认导出 `ExplorationPack`。只新增探索支线，不修改旧 DAY 03 世界、主线谜题、口令、奖励或危险逻辑。共享注册、同门菜单、收藏日志、成就与动物渲染由主会话集成。

本关提供 3 个户外发现、11 个室内发现、5 件可入收藏/工具栏的奖励、2 处打卡、1 只可见巡游猫与 2 项支线成就。所有内容可选，不把采集、摸猫或修苗床变成主线通关门槛。

## 入口必须是真门

外景没有另造“温室入口”图标，也没有把桥下河道洞口解释成人行通路。复用原画已有水磨坊正面木门：

- `sharedTarget: "mill"`，门物点 `(317, 436)`，接近点 `(296, 481)`。
- 复用旧 mill 的 baked 轮廓，主程序在同一门上提供“调查水磨”和“进入种子工房”两个明确选择。
- 工房作为水磨坊附属作业间，不要求先解开磨坊主线谜题。
- 室内从前景左侧低石拱门返回；门框是实体，门洞与石阶可走。返回后恢复到原门前。

初次生成背景后墙意外出现另一扇通往户外的开放石拱。这会错误暗示第二条通路，因此二次定向生成把它改成上半玻璃拱窗、下半实心种子柜，并添加对应碰撞。正式背景使用 `seed-workshop-v2.png`。

## 空间、行动与节奏

左侧木地板是种子工房：低工具台、后墙种子抽屉柜、中央分拣桌。右侧陶砖地是附属温室：玻璃窗、长凳、外围花架、低位灌溉装置、幼苗床。两区由中间宽敞地坪连接；主角从门内木地板 `(427, 637)` 进入。

没有给屋顶或厚墙后面虚构可走面积。桌台、种植床、窗前长凳、花架、种子柜、猫碗、门柱均独立标定。猫在两区交界处宽敞地面闭合巡游，不跨桌、不进入花盆，也不阻挡返回路。

修复链的因果顺序：

1. 工具台登记共用小剪刀借用权，纸签说明清理干茎、开低阀、给花架边水壶接水。剪刀使用后归位，原画继续显示实体符合状态。
2. 桌边阅读植物图鉴，理解“先疏通、后浇水；根还活着不要拔掉”。
3. 拿剪刀清理低位滤网并打开小阀。交互对象明确是低位出口，不是墙上高于主角头顶的大轮盘。
4. 疏通后操作花架下真实绿色水壶，接半壶水待用。
5. 理解图鉴且接水完成后，沿木框边给幼苗浇水，苗床贴回精确注册的恢复态局部图；水壶用后归位。
6. 幼苗恢复后取一包留给路人的勿忘我种子。桌上是多包种子，文案明确只拿最上面的一包。

恢复图不让幼苗瞬间变成巨大花束，仅由低垂变为挺立，土色略湿，保持自然时间感。桌边花笺、桥下水声、窗景和小猫分散在可自由选择的节奏里。
