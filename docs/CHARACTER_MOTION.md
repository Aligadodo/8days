# 角色动作规范

## 目标

角色移动必须让玩家读到“起步—落脚—换腿—收势”，并在任意鼠标路线中保持面向稳定。动作服务操作反馈，不改变路径、碰撞或危险判定。

## 运动参数

- 目标速度：`175 world px/s`。
- 起步响应：`9.5`；刹停响应：`13`，使用与帧率无关的指数逼近。
- 换腿间隔：每 `30 world px` 一次；动画帧、脚步声和地面反馈都由累计路程驱动。
- 身体上抬峰值：`2.4 px`；最大前倾约 `2°`；落脚缩放不超过 `1.8%`。
- 待机仅保留小于 `1 px` 的呼吸起伏，避免角色站立时像悬浮。
- “减少动态效果”关闭上抬、倾斜、缩放和换腿动画，但不移除方向反馈。

## 地面反馈

- 雨地与雷雨山谷：扩散水纹，约 `0.72s` 消失。
- 雪地：浅色脚印，约 `1.7s` 消失。
- 其他地表：低透明度鞋印；秋日河湾使用木质脚步音，其余按草地或石材音色分组。

## 扩展规则

后续新增跑步、推拉、受惊、跌倒或撑伞动作时，必须保持角色头部高度、脚底锚点、画布留白和轮廓密度一致。优先扩充状态，不以更强的循环抖动替代真正的姿势变化。
