# 开发路线

## 阶段 0：项目与方向归档 — 已完成

- 独立目录和版本库
- 设计文档结构
- 九张概念图语义化归档

## 阶段 1：春日花谷五分钟原型 — 可玩初版已完成，等待试玩反馈

- 移动、碰撞和镜头
- 五格快捷栏
- 折叠式菜单
- 两种危险预警
- 三件可用道具
- 四条线索与口令
- 死亡重来和本地存档

当前初版已经覆盖以上功能。下一轮根据试玩结果调整移动手感、危险反应时间、地图密度和线索距离。

验收条件：玩家不阅读外部说明，也能在 5–10 分钟内理解目标、至少识别一种危险，并完成一次口令输入。
