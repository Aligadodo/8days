# 操作与地图参考分析

## 目标

本轮只采样公开游戏的交互原则、信息层级和地图组织方式，不复刻角色、地图、贴图、文案或具体关卡。参考结论服务于《春日花谷》原型 0.2 的鼠标操作与画面清晰度改造。

## 参考样本

### Stardew Valley

官方介绍把耕种、采矿、战斗、钓鱼、采集、关系与社区恢复放在同一个生活世界中；官方 Wiki 的成就页面则展示了可见的长期目标、灰色未解锁状态和收集奖励。由此提炼的原则是：同一张地图支持多种轻量活动，主线之外的收集与小目标被持续记录，但不要求每项活动都转化为战斗力。

来源：[Stardew Valley — About](https://www.stardewvalley.net/about/)、[Stardew Valley Wiki — Achievements](https://wiki.stardewvalley.net/Achievements)

### UnderMine

官方页面将其描述为动作冒险 roguelike：玩家深入矿井、发现秘密，并在死亡后用已取得的资源强化下一次尝试。可借鉴的不是具体矿洞美术，而是三点结构：俯视场景按小区域组织；地标和资源形成高对比焦点；失败、学习和再次探索组成短循环。

来源：[UnderMine — Steam](https://store.steampowered.com/app/656350/UnderMine/)

### Core Keeper

官方页面强调地下生态区、采矿、遗物、资源与探索。由此提炼的地图原则是：每个区域需要独立的地表色、边缘材质、资源簇和标志物，让玩家不依赖小地图也能辨认自己所在的位置。

来源：[Core Keeper — Steam](https://store.steampowered.com/app/1621690/Core_Keeper/)

### Diablo 系列的鼠标移动

暴雪对经典《Diablo》的操作说明明确采用左键点地移动、按住左键持续移动，并让高亮物品可通过点击后自动走近拾取。《Diablo IV》的官方反馈文章也说明“移动与交互”可以绑定到同一鼠标按钮。

来源：[Diablo — Battle.net](https://news.blizzard.com/en-us/article/24055600/face-the-lord-of-terror-in-diablo-now-available-on-battle-net)、[Diablo IV Open Beta Retrospective](https://news.blizzard.com/en-us/article/23938289/diablo-iv-open-beta-retrospective-transforming-feedback-into-change)

### Machinarium

官方页面强调收集物品、环境谜题和逻辑解谜。对本项目有价值的原则是把调查行为绑定到场景本身：玩家点击世界里的目标，角色负责走到合适距离，界面不再要求额外选择“移动模式”或“调查模式”。

来源：[Machinarium — Amanita Design](https://amanita-design.net/games/machinarium.html)

## 落地规则

### 鼠标优先

- 左键点击空地：计算可行路径并自动移动。
- 按住左键拖动：约每 90 毫秒更新目标，形成连续跟随。
- 左键点击可交互物：高亮目标，自动走到交互距离并调查。
- 右键：取消当前自动移动。
- WASD、方向键和 E 保留为备用与无障碍输入，键盘移动会接管并取消当前路径。

### 地图可读性

- 把大地图拆成出生磨坊区、河桥区、风口高地、花田蜂场和山顶小屋五个视觉房间。
- 每个房间至少具备一种独立地表色、一种边缘材质和一个大轮廓地标。
- 路径、河岸和建筑形成清楚的前后层级，装饰物不参与碰撞。
- 可交互物使用闪光；鼠标悬停使用细框；移动目标使用短点线和落点标记。
- 危险仍由世界内迹象提示，不让自动寻路替玩家规避危险。

### 内容丰富度

- 每个视觉区域配置主线、工具、今日小事、自然观察中的两至四种，而不是只摆放主线钥匙。
- 收集与成就记录在原有日志抽屉内，避免增加独立功能页面。
- 完成态熄灭主动光边但保留重复文本，使场景不会因为收集后变成不可点击的空壳。
- 成就奖励以记录、外观和回忆为主，不提供永久危险抗性。

### 清晰像素

- 逻辑视野从 `960×540` 缩近到 `800×450`，角色和交互物在同样显示尺寸下更易辨认。
- Canvas 使用 `1600×900` 的 2 倍内部缓冲绘制，再映射到 16:9 显示区域。
- 禁用图像平滑，并只在整数世界坐标绘制关键轮廓。
- 草地纹理改用小尺度点线和簇状装饰，避免 32 像素大色块形成模糊棋盘感。

## 暂不照搬的部分

- 不加入矿工游戏的战斗、随机房间、资源刷取和数值成长。
- 不让点击移动自动绕开阵风、坠枝等知识型危险。
- 不复制参考游戏的美术资产、角色造型、UI 图标或关卡布局。
