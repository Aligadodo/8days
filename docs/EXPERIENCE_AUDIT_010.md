# 0.10 体验整修与逐关设计审视

日期：2026-09-07。基于当前八关代码、八张环境图和本地浏览器实际操作。不是外部玩家测试报告，也不把自动化脚本等同于真实玩家评审。

## 本轮判断

最先损害体验的不是内容数量，而是玩家看见的东西与游戏规则不一致：看似空地却不能走；有路却沿隐藏网格绕行；文字写着猫但世界中没有猫；点击对象的光圈比对象本身更显眼。先修复这些约定，再增加任务数量。

## 已实现的基础约定

| 系统 | 旧问题 | 0.10 实现 |

| 小地图 | 无位置与探索记忆 | 地图缩略图、当前位置/方向、镜头框、已发现物件、路线、近处危险；未知深色、探索过暗色、附近较亮；可折叠 |

| 失败负担 | 解过题还要从出生点重走 | 每次主线完成记录地点；死亡回最近主线检查点，保留探索/小事/提示，给予短暂安全时间 |
| 谜题操作 | 大多选项按答案排列；逐步试错能穷举 | 固定种子洗牌，排序全部提交后统一判断；保留玩家排法供检查，不逐步播报正确答案 |
| 记忆与终点 | 输入口令时反复切日志 | 口令面板可以展开本关记忆卡，玩家仍需按符号重排 |
| 提示 | 地图与题内提示分别扣次数 | 同一题共用已拆提示层级并持久化，重复阅读不扣次数 |
| 存档 | 重复“好”字被去重，菜单可能覆盖进度 | 印章按关卡身份计算；未开始关卡不写空存档；旧 v2 存档可继续使用 |
| 视口与菜单 | 窄屏只有一条很矮的画面、缺全屏入口 | 视口随长宽比调整，不拉伸人物；竖屏有足够地图高度；五格口袋栏中第 5 格直达日志 |

## 可见的任务反馈

- 猫：纸箱内小猫 → 主角走近停下 → 短暂动作 → 小猫出箱、移至檐下、喵声。状态在重开后保留。
- 同事、孩子、乘客、旅人、摄影师：真实角色站在现场，不再是文字圆圈；完成时提供台词与短反馈。尚未做多阶段 NPC 行为树。
- 电脑：屏幕亮 → 屏幕关；蕨叶：受阻状态 → 恢复状态；雪人：帽子落在旁边 → 戴好帽子。
- 蜂、蝠：具有实体和轻微悬浮；完成后改变位置，作为让路/返回的可见回应。
- 机关：按类别使用排水篦、阀门、地图架、信号、行李、灯具等实体；部分灯具完成后点亮。
- 瀑布踏石：解谜前为深水，解谜后新增可见踏石，并更新可走区域。不是仅播放一个成功提示。
- 排水与分水机关继续解除对应危险。其他主谜题大多仍以记忆奖励和局部灯光回应，不宣称全部具备大型环境变形。

## 必须补充，但本轮不伪装成已完成

1. **背景分层**：目前地图仍是整幅环境绘制。新增实体可以前后遮挡，但背景里的树冠/墙体不能正确遮住人物，部分背景物和可交互精灵重复。下一批以花谷/瀑布作为分层样板，制作地面、墙面、前景、道具四层。
2. **从答题回到世界操作**：优先做一条完整的跨物件链，不再横向添加十种菜单题。先拿/用/改变世界，再把认知写入日志。
3. **支线两步化**：观察需求 → 选择帮助方式 → 环境/NPC 作出回应；保持可跳过，不能用道德扣分或强迫全收集。
4. **危险语法**：静止预兆、声音、实际发生、余波各有独立状态。目前仍是周期区域与程序化粒子，并非泥石流/列车等完整物理模拟。不可将“随机挨一次”当教学。
5. **探索奖励**：先添加安静观察点、近路、日记照片和 NPC 后续对话；不增加成就大厅，不以反复死亡刷奖。
6. **真实无说明试玩**：至少观察 5 位玩家，记录首次发现机关时间、无效点击、绕路距离、同一危险重复死亡和是否理解最终寓意。当前没有这组数据。

## 下一轮验收门槛

- 任一阻挡都能在画面中指出对应墙、水、栏杆或高差；不得用没有解释的透明区域补地图错误。
- 一条跨物件谜题至少产生一次持续可见的环境变化，并改变之后的行动选择。
- 可选小事至少有一个玩家能看见的后续，不依赖结算数字证明自己做过。
- 需要帮助时两次操作内可找回下一目标；不需要帮助时不把答案箭头常驻在地图上。
- 不增加无意义赶路、重复输入口令、强制收集或死亡次数指标。
