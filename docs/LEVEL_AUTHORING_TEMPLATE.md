## H. 数据与试玩

建议记录：

- 每个节点的首次看见、首次点击、首次有效尝试与解决时间；
- 错误类型和次数，而不只记录总失败；
- H1/H2/H3 各层提示触发率；
- 危险预警出现、玩家开始反应、受击和死亡时间；
- 口令输入次数、是否存在暴力尝试；
- 静音与正常音频两种条件下的完成差异；
- 玩家在结束后能否用自己的话复述本关一条规则和一个生活片段。

## I. 上线前检查

- [ ] 新规则不超过两个，并且先安全教学。
- [ ] 所有必要证据在解题前可访问。
- [ ] 不存在关键像素搜寻和作者私有联想。
- [ ] 错误可以快速恢复，不丢失永久进度。
- [ ] 关键动作具有开始、命中/变化、完成三段反馈。
- [ ] 危险具备视觉、音频、时间和安全路线四项公平性。
- [ ] 重要声音具备字幕或视觉等价信息。
- [ ] 静音、单声道和不依赖颜色的条件下可通关。
- [ ] 音效有变体、冷却和优先级，连续操作不疲劳。
- [ ] 所有素材来源与许可证已经登记。
- [ ] HUD 未增加新的顶层功能页面。
- [ ] 存档、死亡重试和旧版本迁移已验证。
