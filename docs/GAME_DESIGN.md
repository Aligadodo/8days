# 游戏设计总纲

## 当前实现修订 · 0.11 危险事件

死亡必须先在世界内发生，再复盘。具体时序、各关实施范围与后续交互规范见 `HAZARD_INTERACTION_011.md`。

- 招牌完整流程：落灰 / 吱呀预警 1.5 秒 → 下落 0.42 秒 → 落地命中或落空 → 主角倒下 / 渐隐 → 灵魂升起 → 命中后 2.45 秒出现重来提示。
- 16 个危险改用场景局部事件时钟；首次事故需在镜头内并且玩家靠近，预警至少 1.5 秒。落物本次探索只发生一次，水电等持续风险会消退后重新预警。
- 重来保留知识、主线检查点和累计游戏时间，但重置危险物理状态，给 6 秒保护；本条替代 0.10 的“危险周期继续”。
- 复盘展示实际游戏时间、观察到的前兆与可执行撤离办法。无血腥、强闪白或长时间禁止重试。
- 同一危险重复死亡后的自适应教学、首次非致命演示仍是下一步工作，不假定已实现。

## 当前实现修订 · 0.10

本节覆盖下文旧版本中互相冲突的实现说明。具体审视见 `EXPERIENCE_AUDIT_010.md`。

- 常驻 HUD：时间天气、折叠目标、全屏/背包、五格口袋栏（4 个记忆道具 + 日志）、可折叠探索小地图。
- 世界内取消常驻光圈、菱形、方框、名称与离屏目标箭头；仅悬停真实物件时描细轮廓。按需定位只标记小地图 8 秒。
- 地形由 `src/campaign/worldDesign.ts` 的独立区域定义；旧 `LevelDefinition.route` 只保留历史元数据，不参与通行。
- 鼠标导航直线优先，八方向绕障，不穿角。活动危险可绕则绕，无路则在边缘等待；玩家仍需观察预警并主动离开自己所在的危险区。
- 死亡保留探索记忆，回到最近一次主线解谜地点；危险周期继续，重来短暂保护。旧版“回出生点并重置周期”的描述不再适用。
- 顺序题先排完再统一判断，不逐步暴露答案。提示在场景与谜题面板共用并持久化。
- 终点可原地展开记忆卡；四位口令机制暂保留。它是后续差异化改造重点，不代表八关最终设计质量已达到目标。
- “今日照片”、同一危险重复死亡后的自适应教学、NPC 多步委托仍属于设计目标，不是当前已实现功能。

## 游戏定位

《今天，也要好好活着》是一款 Q 版像素风的单关卡式探索解谜游戏。每关描绘一个普通日子：通勤、工作、旅行或休息。玩家需要观察环境、规避具有明确预警的危险、收集四段生活线索并抵达终点。

游戏不依赖血腥表现。死亡用于反馈知识，而不是惩罚玩家。真正的成长来自玩家对世界规律的理解。

## 核心循环

1. 获得“今天要做的一件小事”。
2. 在固定地图中自由探索。
3. 识别环境预警并选择安全路线。
4. 通过四个主谜题各获得一件关卡道具。
5. 通过观察、使用道具和改变环境解开四条生活线索，日志记录图标、证据和已经推导出的数字。
6. 抵达终点，根据场景给出的图案顺序重组四位口令。
7. 获得一张今日照片和一个文字印章。

## 失败与记忆

- 严重危险通常直接导致死亡，不设计传统生命值。
- 死亡画面不展示伤口或尸体，只显示时间、原因和一条可执行的经验。
- 重来后保留已经发现的口令线索、谜题道具、支线记录、危险知识和辅助设置。
- 角色位置与动态危险周期重置。
- 连续被同一危险击中两次后加强预警；三次后可显示安全路线。

## 关卡目标

- 初次通关：12–18 分钟。
- 熟练通关：5–8 分钟。
- 预期死亡：1–3 次。
- 单关主线道具：固定 4 件。
- 单关主要危险：0.8 内容版固定 2 种。
- 单关生活线索：固定四条。

## 界面原则

常驻界面只有时间天气、单一目标卡、全屏与背包按钮和四格快捷栏。目标卡可折叠“现在做什么”与分层提示；背包抽屉包含道具、生活日志、存档和设置，打开时暂停世界。交互采用环境光边和短提示，不建立额外的任务中心或成就大厅。

## 操作原则

桌面端采用鼠标优先：左键点地移动，按住左键持续更新目的地，点击可交互物后自动走近调查，右键取消移动。键盘移动和 E 键交互作为备用输入。自动寻路只处理静态地形和建筑碰撞，不替玩家规避动态危险，观察与判断仍是玩法的一部分。

## 解谜原则

- 谜题难点来自理解和组合环境规则，不来自寻找没有提示的关键像素。
- 每个谜题必须在游戏世界内给出全部必要证据，并服务于关卡情节或环境变化。
- 新规则先在无致命惩罚的区域展示和教学，再由危险、路线或组合谜题进行测试。
- 尝试、局部正确、错误、条件不足和完成具有可区分的视听反馈。
- 谜题错误可快速复位；停滞后按环境、注意力、关系、动作四层逐步给提示。

具体制作与验收规范见 `docs/PUZZLE_AUDIO_ITERATION_PLAN.md` 和 `docs/LEVEL_AUTHORING_TEMPLATE.md`。

## 音频原则

- 音乐服务于情绪段落，不持续无间断循环；无音乐时由分区环境声维持空间感。
- 点击、移动、道具、谜题、危险和完成使用稳定的声音语义，同一高频事件需要变体与冷却。
- 关键声音同时提供动画、方向标记或文字声效字幕，主线不能依赖听力或颜色识别。
- 设置提供主音量、音乐、效果和环境独立控制，保留单声道与重要声音字幕选项。

## 内容层级

- 主线：每关一条，只在 HUD 展示当前一步。
- 今日小事：0.8 每关两件，不阻断通关，提供生活片段并进入结算统计。
- 自然发现与成就：保留为正式资产与扩展探索阶段的内容层，不在 0.8 的八关主流程中占用界面。

当前可推进主线使用暖金光边，尚未解锁的主线为灰色，今日小事使用薄荷绿，完成态统一变绿；普通装饰没有光边，危险使用红/黄/蓝等与主题匹配的虚线预警区。详细规则见 `docs/CAMPAIGN_08_SPEC.md`。

## 长线结构

八关通关印章依次组成“好好生活，明天再见”。角色不会获得降低风险的永久数值成长；跨关奖励以服装、照片、房间摆件和日志内容为主。
