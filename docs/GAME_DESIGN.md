# 游戏设计总纲

## 当前实现修订 · 0.16 发现玩法的入口

既有可选物资循环不变，但不再把商店和成就埋在日志层级。抽屉顶栏直接提供背包、商店、伙伴、成就、更多；主线线索/生活日志/存档/设置归更多。底部第五口袋格直达成就，右上按钮显示「背包 / 商店」。成就页统一列出4项八日累计和当前日2项地方成就，条件、进度与完成筛选平铺，不新增永久常驻清单。

非强制生活引导可以关闭并找回，升级旧存档也显示一次。附近物资只推荐已探索或近处、条件具备、安全且精确可达的来源；推荐点击走正常导航，不传送、不偷看未知目标。剩余来源计数与可导航条数是不同指标。采集前后、刷新、换场景和危险变化重新核验，路线计算缓存，冷却显示仍实时更新。

再生来源32→47；138条生活动作中含41个一次容器、47处再生、50处观察，其中18条和旧发现共用实物。DAY01出生人行道近处提供第一份修剪余叶，其余分布遵从各图实物，DAY06室内不为凑数拆雨披、靴或热炉。DAY05共享纸抽屉和DAY08公共矿样罐改轮次补给，旧领取记录升级后先等完整420秒，不立即再奖。清单见 `life-016/CONTENT.md`，方案与证据见 `INTERACTION_016_PLAN.md`、`INTERACTION_016_RELEASE.md`。

## 当前实现修订 · 0.15 可选物资循环

在原主线与生活册之外增加“探索容器/采集 → 物资堆叠 → 出售兑换 → 补给或同行伙伴 → 继续探索”。这一循环使用游戏币，不涉及现实付费，不要求刷钱才能通关。数据、定价与限额详见 `life-015/ECONOMY.md`，逐关记录见 `LIFE_015_RELEASE.md`。

- 16 个场景共 127 条生活动作定义，13 条复用原发现；容器永久取一次，采集按活跃游戏秒数再生，观察可重复无奖励。
- 具体物件产出符合其身份：纸盒出纸、茶壶出茶、草叶出草，不把混装随机池用于单一物资。一次领取按种子与节点 ID 固定，刷新、死亡、重玩不重抽。
- 真正物资与主线线索/纪念收藏分开；只有物资可出售和使用。每类最多 999，金币上限 999999。交易失败不扣款不消耗。
- 同种伙伴可多次领养并分别编号，最多拥有 12 只/同时跟随 3 只；跟随不是自动采集或免伤系统。
- 点心/温茶暂时改善行走速度，伙伴零食收紧跟随距离；计时在背包/后台暂停，同类效果替换，不叠加强度。
- 生活奖励、成就和队伍跨天保留；删除全部存档仍是唯一清空全部记录的主动操作。

## 当前实现修订 · 0.14 主线以外，也有值得停留的地方

本节覆盖下文旧版本里“收藏待扩展”“只有主线活动”的描述。八个室外关卡各新增一张独立子地图，每张至少两块可辨识活动区。24 个户外发现与 75 个室内交互构成 99 个新发现节点，其中 38 项归档奖励（含工具）、14 处打卡、16 项地方成就、9 只巡游动物。数量由 `src/campaign/exploration/day01.ts`—`day08.ts` 统计；制作与最终验收边界见 `EXPLORATION_014_RELEASE.md`。

主线仍是每关四谜题、一次口令与两项今日小事；自由探索是并行目标，不新增必收物或永久免伤能力。进入房间、读物、打卡、借工具、按环境证据完成小操作链、留下自己的记录构成第二条循环。玩家可以只通主线，也可以走完主线后重访；重玩不会清空本日新增收藏。

- **门是世界物件**：先导航到原画真实门前，再切换场景。共用门通过“进入/调查”双选择保持原主线可操作。DAY04 观测所位于已存在的东岸高台，需先解开踏石通路，不为了早进屋新增穿水捷径。
- **空间不以图标代替**：室内维护独立可走区域、家具障碍、支撑面、操作站位、出口与小地图探索阴影。返回无需收集钥匙、完成支线或主线。
- **自由发现有因果**：工具/知识前置齐备才结算；修伞、广播、苗床、记录纸与菌床使用对应状态素材。烹饪试做、留舍路线与失物核对使用世界内调查顺序，不新增答案面板。当前不是物理制作或推箱系统。
- **收藏不等于搬空房间**：共用图鉴、样品和失物使用拓印、抄录、借用或取一份的语义；原画保留的唯一实体不得声称已拿走。稳定 ID 保证反复点击、进出与重玩不重复授奖。
- **动物不是文字框**：猫、狗、鼠使用共享透明精灵在作者标定的安全地面巡游；玩家靠近时暂停，点击提供独立反馈。没有捕捉、战斗、饲养数值或完整 NPC 作息。
- **已有抽屉承载增量**：背包显示归档物，日志显示本日发现/证据、地方成就与八日收藏计数；常驻 HUD 仍为时间/折叠目标/背包全屏/五格口袋与可折叠小地图。
- **存档明确分区**：v2 新增发现标记、访问房间与各房间探索记录；室内保存仍使用室外门前检查点，刷新返回室外。室内不承载致命事件，室外危险在室内暂停，不声称支线会消除室外事故。

进入室内的切场景、声音、发现反馈由共享引擎处理；逐关作者只维护本日数据与素材。静态几何检查、运行时逻辑测试、浏览器实机和真人无说明试玩是不同层次，任何一层通过都不能代替其他层。

## 当前实现修订 · 0.13 物件必须属于这个世界

本轮空间与美术验收以 `VISUAL_ACCEPTANCE_013.md` 为准，覆盖八关 56 原对象和 7 个机关，分开验证画风、比例、安装、遮挡、站位、状态与玩法。各关数据在 `src/campaign/worlds/day01.ts`—`day08.ts`；共享 schema 在 `worldSchema.ts`。

优先把原画中的真实门、井盖、货箱、灯和桌上物变成可交互物，取消第二份悬浮图标。独立物件需要真实支撑说明和尺度。办公室供电拉柄绑定壁柱检修面板，开启低隔墙中的真实维修门洞；不把朝向电梯厅的原黑门误作跨墙柱通路。矿洞支线从轨道边调查破墙壁龛，不再沿洞壁铺假路。门/墙开态使用同场景位图，鼠标命中与显示共享注册位置和透明轮廓，已消失机关不再吃点击。

剧情名称、提示和完成文本必须对应画面实物，不允许把灯称为水壶、把货箱称为巨大秤、把已经存在的桥描述为临时生长出来。渡船/吊篮两道配重题同时修正唯一解条件；关卡口令及已有进度不变。下述 0.12 的活动档案柜和可进入旧壁龛设计由本节覆盖。

## 当前实现修订 · 0.12 空间与世界机关

以 `WORLD_CALIBRATION_012.md` 和 `worldDesign.ts` 为当前空间契约：地面、静态障碍、物件锚点、操作站位、条件通路分开维护；八关重新标定，整段路线与每步移动双重碰撞验证。物件必须从指定可达侧操作。

办公室新增供电拉柄打开档案柜暗门；矿洞新增小锤敲开裂墙、找到夕阳手记的可选支线。机关需要可感知线索、动作/声音、可见状态变化、同步通行变化，不能是只改一句文本。HUD 不新增页面，工具和收藏纳入已有背包/日志。机关解锁随存档保留，取消未完成动作不提交状态；旧版检查点迁至可达站位，知识进度不清空。


## 当前实现修订 · 0.11 危险事件

死亡必须先在世界内发生，再复盘。具体时序、各关实施范围与后续交互规范见 `HAZARD_INTERACTION_011.md`。

- 招牌完整流程：落灰 / 吱呀预警 1.5 秒 → 下落 0.42 秒 → 落地命中或落空 → 主角倒下 / 渐隐 → 灵魂升起 → 命中后 2.45 秒出现重来提示。
- 16 个危险改用场景局部事件时钟；首次事故需在镜头内并且玩家靠近，预警至少 1.5 秒。落物本次探索只发生一次，水电等持续风险会消退后重新预警。
- 重来保留知识、主线检查点和累计游戏时间，但重置危险物理状态，给 6 秒保护；本条替代 0.10 的“危险周期继续”。
- 复盘展示实际游戏时间、观察到的前兆与可执行撤离办法。无血腥、强闪白或长时间禁止重试。
- 同一危险重复死亡后的自适应教学、首次非致命演示仍是下一步工作，不假定已实现。

## 游戏定位

《今天，也要好好活着》是一款 Q 版像素风的单关卡式探索解谜游戏。每关描绘一个普通日子：通勤、工作、旅行或休息。玩家需要观察环境、规避具有明确预警的危险、收集四段生活线索并抵达终点。

游戏不依赖血腥表现。死亡用于反馈知识，而不是惩罚玩家。真正的成长来自玩家对世界规律的理解。

## 核心循环

1. 获得“今天要做的一件小事”。
2. 在固定地图中自由探索。
3. 识别环境预警并选择安全路线。
4. 通过四个主谜题各获得一件关卡道具。
5. 通过观察、使用道具和改变环境解开四条生活线索，日志记录图标、证据和已经推导出的数字。
6. 抵达终点，根据场景给出的图案顺序重组四位口令。
7. 获得一个文字印章；可选打卡与收藏另在自由探索中记录（自动生成通关照片仍是设计目标）。

## 失败与记忆

- 严重危险通常直接导致死亡，不设计传统生命值。
- 死亡画面不展示伤口或尸体，只显示时间、原因和一条可执行的经验。
- 重来后保留已经发现的口令线索、谜题道具、支线记录、危险知识和辅助设置。
- 角色位置与动态危险周期重置。
- 连续被同一危险击中两次后加强预警；三次后可显示安全路线。

## 关卡目标

- 初次通关：12–18 分钟。
- 熟练通关：5–8 分钟。
- 预期死亡：1–3 次。
- 单关主线道具：固定 4 件。
- 单关主要危险：0.8 内容版固定 2 种。
- 单关生活线索：固定四条。

## 界面原则

常驻界面只有时间天气、单一折叠目标卡、全屏与背包按钮、五格口袋栏和可折叠小地图。目标卡可折叠“现在做什么”与分层提示；背包抽屉包含道具、生活日志、存档和设置，打开时暂停世界。交互只在悬停真实物件时使用细轮廓和短提示，不建立额外的任务中心或成就大厅。

## 操作原则

桌面端采用鼠标优先：左键点地移动，按住左键持续更新目的地，点击可交互物后自动走近调查，右键取消移动。键盘移动和 E 键交互作为备用输入。寻路优先直线，再绕过建筑与当前危险；无路时在边界等候。它不替玩家离开脚下刚出现的危险，观察与判断仍是玩法的一部分。

## 解谜原则

- 谜题难点来自理解和组合环境规则，不来自寻找没有提示的关键像素。
- 每个谜题必须在游戏世界内给出全部必要证据，并服务于关卡情节或环境变化。
- 新规则先在无致命惩罚的区域展示和教学，再由危险、路线或组合谜题进行测试。
- 尝试、局部正确、错误、条件不足和完成具有可区分的视听反馈。
- 谜题错误可快速复位；停滞后按环境、注意力、关系、动作四层逐步给提示。

具体制作与验收规范见 `docs/PUZZLE_AUDIO_ITERATION_PLAN.md` 和 `docs/LEVEL_AUTHORING_TEMPLATE.md`。

## 音频原则

- 音乐服务于情绪段落，不持续无间断循环；无音乐时由分区环境声维持空间感。
- 点击、移动、道具、谜题、危险和完成使用稳定的声音语义，同一高频事件需要变体与冷却。
- 关键声音同时提供动画、方向标记或文字声效字幕，主线不能依赖听力或颜色识别。
- 设置提供主音量、音乐、效果和环境独立控制，保留单声道与重要声音字幕选项。

## 内容层级

- 主线：每关一条，只在 HUD 展示当前一步。
- 今日小事：0.8 每关两件，不阻断通关，提供生活片段并进入结算统计。
- 自由探索：0.14 在八日扩展包实现房间、收藏、自然观察、打卡、地方成就与动物；不占用主线解锁条件。

交互细轮廓仅在悬停时出现，普通装饰没有光边；危险常态使用源头、碎屑、水纹、运动与重要声音字幕，完整危险边界只在辅助设置开启时显示。0.8 文档中常驻标记为历史方案。

## 长线结构

八关通关印章依次组成“好好生活，明天再见”。角色不会获得降低风险的永久数值成长；跨关奖励以服装、照片、房间摆件和日志内容为主。
