# 游戏设计总纲

## 游戏定位

《今天，也要好好活着》是一款 Q 版像素风的单关卡式探索解谜游戏。每关描绘一个普通日子：通勤、工作、旅行或休息。玩家需要观察环境、规避具有明确预警的危险、收集四段生活线索并抵达终点。

游戏不依赖血腥表现。死亡用于反馈知识，而不是惩罚玩家。真正的成长来自玩家对世界规律的理解。

## 核心循环

1. 获得“今天要做的一件小事”。
2. 在固定地图中自由探索。
3. 识别环境预警并选择安全路线。
4. 收集最多五件关卡道具。
5. 找到四条生活线索，日志自动记录图标和数字。
6. 抵达终点，按图标顺序输入四位口令。
7. 获得一张今日照片和一个文字印章。

## 失败与记忆

- 严重危险通常直接导致死亡，不设计传统生命值。
- 死亡画面不展示伤口或尸体，只显示时间、原因和一条可执行的经验。
- 重来后保留已经发现的口令线索、危险知识和辅助设置。
- 本轮拾取的普通道具和环境状态重置。
- 连续被同一危险击中两次后加强预警；三次后可显示安全路线。

## 关卡目标

- 初次通关：12–18 分钟。
- 熟练通关：5–8 分钟。
- 预期死亡：1–3 次。
- 单关常规道具：3–5 件。
- 单关主要危险：2–4 种。
- 单关生活线索：固定四条。

## 界面原则

常驻界面只有时间天气、目标图标、背包按钮和五格快捷栏。背包抽屉包含道具、生活日志、存档和设置，打开时暂停世界。交互采用环境旁的短提示，不建立额外的任务中心或功能页面。

## 长线结构

八关通关印章依次组成“好好生活，明天再见”。角色不会获得降低风险的永久数值成长；跨关奖励以服装、照片、房间摆件和日志内容为主。
