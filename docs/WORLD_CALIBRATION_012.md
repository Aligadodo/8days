# 0.12 · 可信的地面、物件与秘密通路

日期：2026-09-08。此文覆盖早期“大块地面 + 自动吸附物件”的实现说明。坐标唯一来源为 `src/campaign/worldDesign.ts`，统一使用 1600 × 900 世界空间。已有原画和背景图片继续保留，不把概念图片当碰撞数据。

## 设计目标

玩家应能根据画面预判：哪里能站，什么挡路，站在哪里能操作，以及操作后世界怎样改变。秘密不是没有提示的隐形开关，更不能靠穿墙触发。此次优先修复空间可信度，再增加两条有因果、可取消、有收藏回报的机关链。

参考的是 UnderMine 开发者 [Collector Update](https://undermine.game/collector-update) 中“找到书 → 放到书架 → 出现密室通道”的世界交互因果，而非复制它的美术、炸弹系统或战斗。官方 [press kit](https://undermine.game/press-kit) 对探索、秘密和角色发现的定位也与本项目有关。下述小锤、裂墙、档案柜和生活手记是本项目自己的改编设计。

## 空间契约（已实施）

1. **地面层**：多边形空地与精确道路带。水面、崖壁、屋顶、轨道间隙不能因为一大片绿色区域而被当成地板。
2. **障碍层**：具名墙、隔板、桌椅、柜子、树根、帐篷、矿车等。静态实体和机关的脚部占位也加入碰撞；花纹、脚印等贴地线索不制造隐形障碍。
3. **物件锚点**：决定画面落点和悬停形状。背景已有的屏幕、门、桌上茶篮尽量复用背景热区，不再叠一份巨型精灵。
4. **操作站位**：每个物件单独指定 `approach`。只能到达该侧的站位才触发调查；不再统一向下偏移 23，也不再向任意地面吸附 110 像素。
5. **开放状态**：动态地面、墙和门共享同一组状态。开门/破墙提交后重建导航、清掉旧路线；不保留跨过旧障碍的失效路径。

角色采用脚部 9 × 6 椭圆的九点轮廓，不用整张高人物图去挤窄桥。导航网格由 16 改为 8，直线优先，八方向绕行。静态路线使用几何边界交点覆盖检查，不能在两个采样点间漏过薄墙、斜角或地面断层；移动每一步再次验证。静态格点连线有缓存，临时危险仍每次重新判断。

地面误点只允许 14 像素边缘容错；桌子/墙深处的点击不会被转换成另一边的目的地。不可达时说明障碍类型或机关原因。已打开的门让出鼠标热区，点击门洞直接走入。移动、右键与键盘接管可取消未完成动作。

所有 56 个原有目标（32 主线 + 16 支线 + 8 终点）有独立站位。新增 7 个世界实体：3 个办公室机关实体、4 个矿洞实体。它们不是额外的 7 个面板谜题。

## 已落地的机关链

### DAY 02：恢复供电 → 拉柄 → 档案柜暗门

- 暗门前可看见柜子和把手；检查柜子提示柜脚磨痕与通向西侧拉柄的线索。
- 未恢复配电箱时，拉柄只反馈缺电，不消耗道具、不弹新功能页。
- 配电箱解开后，折叠目标改为操作拉柄，小地图定位也指向拉柄，而不是隔墙的火警控制器。
- 操作约 1.15 秒：卡扣声 → 柜子沿轨道滑开 → 门洞与门槛出现 → 通路开放。动画期间碰撞不提前释放。
- 中途取消不提交世界状态；完成后不可关门把自己锁住。
- 电梯厅的控制器、疏散图在门后；安全门密码随后解除楼梯入口。重来与重载保留已打开的世界机关。

### DAY 08：工具篮 → 裂墙 → 生活手记（可选）

- 小锤在矿口轨道旁的工具篮中，拿取后进背包；不占用四段口令的主线槽位。
- 可破坏薄墙有不规则石块、裂纹和微弱透光，不用常驻光圈。普通岩壁仍是岩壁，不鼓励全屏乱点。
- 无锤检查得到工具需求。拿到后点击，走到墙的可达侧，约 1.05 秒内举锤、两次敲击、裂纹加深、碎石扬尘；最后才移除墙的碰撞。
- 碎块留下，壁龛通路与收藏盒显露；未破墙前收藏盒不绘制、不接受点击、不提前出现在小地图。
- 手记写着：“今天没有挖到金子，但陪孩子看了夕阳。”收藏只增加生活发现，不白送主线密码。
- 小锤可复用，不消耗；重复点击不重复领奖。拿取、破墙和开门分别有合成事件音效，并遵守原音量与字幕设置。

### 已有空间谜题补齐

- 瀑布踏石的画面路径与新通行路径使用同一份坐标，避免只画半座桥。
- 花桥本来就在背景中，因此用可见藤门表达“桥在，但入口被锁住”；解开桥脚谜题才开放。
- 普通门锁仍使用已有谜题面板；本轮没有声称将 32 个谜题全部改成直接操纵世界。

## 存档与恢复

继续使用 `one-more-day:campaign:v2`，每关增加 `layoutRevision: 12` 和 `worldFlags`。旧线索、提示、支线、死亡数、已通关天数和印章保留。旧版检查点重新选择最近已完成且当前可达的操作站位，找不到才回安全出生点。已越过办公室控制器的旧存档自动视为拉柄已开，不要求倒退补做新机关。

同版检查点也必须可站立且与出生点连通，不能恢复到另一块封闭地板。物理危险仍按 0.11 在重来时重置；知识、世界解锁和收藏保留。

## 标定与验收工具

- `npm run audit:layout`：逐关检查出生点、所有目标站位和机关站位是否有精确无吸附路径；任一失败返回非零退出码。
- 开发服务器下 `/map-audit.html`：背景、通行层、障碍层、锚点→站位、100 像素网格、机关全开切换、点击检查路线。该页不加载或写入玩家存档，也不是玩家的新功能面板。
- `npm test`：40 项测试。含八关正常顺序推进、全部支线实走、独立家具/墙/深水负样本、亚像素薄墙、旧路线移动保护、隔墙操作拒绝、机关前置/取消/时序、隐藏物防泄露、收藏去重、存档迁移、原 16 危险/灵魂流程回归。
- 实机测试使用 `127.0.0.1:5174` 隔离源，不能重置用户正在使用的 `localhost:5173` 存档。

## 下一阶段（未实施，不混写为完成）

1. **一块压力板 + 可推木箱**：先放在宽阔可撤离房间；箱体格与移动角色分离，推后更新碰撞；提供重置箱子，不允许把主线永久堵死。
2. **小范围回环捷径**：探索后从另一侧解闩，连接已走过区域；必须在小地图明确体现缩短的路，不为隐藏而隐藏。
3. **两种材质的工具反馈**：木板/薄石墙有不同裂纹、声音与工具提示；不加入无提示的资源消耗或炸弹死亡惩罚。
4. **分层地图资产**：现有大背景仍限制局部地形变化的细腻程度；新增机关为原创程序化像素表现，之后应制作与背景细节密度一致的分层资产。不是完整的可破坏沙盒或随机地牢。
5. **真人无说明试玩**：测试是否主动发现拉柄/裂墙、是否理解台阶入口、是否误把崖壁或屋顶当道路；仍需玩家数据，自动化不能证明所有视觉判断都自然。
