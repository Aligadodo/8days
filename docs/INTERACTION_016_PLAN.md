# 0.16 找得到、收得到、用得上

## 用户问题与检查结果

0.15 已经有真实背包、金币、兑换和伙伴，但入口仍是无文字背包图标，商店藏在“道具→兑换”，全局成就在日志底部。只有主线被明显指引；世界对象只在悬停时描边，没有告诉玩家哪些能产出物资、哪些已经取空。数量增长不等于玩家能发现玩法。

本轮不新增大面积常驻面板，也不靠光圈铺满地图。先解决入口、发现、领取、用途、下一目标五段连续体验，再补充贴合原画的资源。

## 交付范围与验收标准

1. **入口可见**：现有背包按钮有文字，底部第五格直达成就；抽屉直接展示背包、商店、伙伴、成就、更多。线索/日志/存档/设置收在更多，不删除现有能力。
2. **首次引导可执行**：一次可关闭的非强制提示，提供找物资、看商店、看成就等实际按钮。老存档升级同样可见，关闭后可找回；不篡改玩家进度，不暂停或遮住整幅地图。
3. **附近物资可信**：按当前场景和已探索范围推荐最多三项，说明产出和状态。精确站位不可达、前置未齐或正在危险区的物资不推荐；未知区域不泄漏具体目标。点前往仍使用正常导航和采集动作。
4. **冷却/取空有说明**：显示场景可收集数、一次箱柜已领取数、采集冷却及最早再生时间；悬停实物才出现动作/产出短说明，不新增常驻光圈。观察不伪装成有掉落的采集。
5. **成就可理解**：全局生活成就和本日地方成就集中展示，条件、当前进度、完成状态和筛选可读。不能把普通任务线索算成可出售物资。
6. **资源实物一致**：八日内外场景补充可再生点，优先出生附近或自然探索路径。逐点追踪原画位置、真实地面站位与产出；不拆他人的家具或取走私人档案。保持一次箱柜与共享补给的区别。
7. **回归不降低门槛**：现有214项基线、新增UI/发现测试、实际命中/行走、八日布局与探索审计、构建。隔离浏览器验证旧存档、首次入口、搜集—兑换、成就筛选、键盘及窄布局。无图形测试不冒充全部节点手动遍历。

## 并行所有权

- 界面任务：`src/main.ts`、`src/style.css`、UI helper/测试和原经济测试末尾的UI合同。
- 运行时任务：`CampaignGame.ts`、`types.ts`、物资机会计算/导航、相关回归。
- 内容任务：DAY03—08生活数据、补充内容审计。
- 主任务：DAY01—02生活数据、集成测试、浏览器验收、版本与设计/发布文档。

所有任务共用一份场景/存档，不各建一套背包或独立货币。接口使用 `view.supplies` 与 `focusLife(id)/findNearbySupply()`；菜单关闭后才开始移动。

## 本轮非目标

不新增付费交易、任务通关付费门槛、自动挂机、无条件全地图资源导航、无限开箱、所有家具可破坏、所有箱柜动画或背景逐像素互动。原冷却、价格和伙伴上限保持，先观察真实发现与使用流程再调经济。
