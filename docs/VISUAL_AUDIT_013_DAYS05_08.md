## 资产、产物和验证边界

- 新增原图/提示词/可复现打包：`design/scene-013/cave/`。完整内置生成及定向编辑提示在 `PROMPTS.md`。
- 生产 PNG：`public/assets/scene-013/cave/wall-alpha.png`、`hammer-alpha.png`、`cache-alpha.png`、`vine-alpha.png`。
- 内置生成器最初的透明请求及重试实际输出 RGB 棋盘，未冒充 alpha 交付。采用内置编辑生成明确纯品红技术底，`build-alpha.ps1` 仅机械去除高饱和品红，保存真正 32bpp RGBA；中性纸面、钢铁与石头高光不被剔除。SceneRaster 只读预处理透明 PNG。
- 浏览器审图：在 `127.0.0.1:5174/map-audit.html?visual=1` 逐一查看 DAY 05、06、07，及 DAY 08 的关/全开图层；页面不读写用户存档。确认重复矿车/日晷/门/水池已消失，物件比例收敛，矿洞不再出现亮色补路和棋盘矩形。
- 导航检查：本组最终 `npm run audit:layout` 八关站位全部可达。中途两处窄路因整块道具碰撞断开，已按真实牌脚和站位重新修复，不通过扩大整条虚假地面解决。
- 自动测试/构建由主会话合并跑最终结果；本组一次构建通过。旧测试中“壁龛站位必须开墙后才能走到”和“墙与里面收藏锚点不得重叠”已明确通知主会话按浅壁龛语义调整。
- 不冒充已完成：本组审图页“全开”同时算收藏已取，不能代表“墙开而手记未取”的中间态实机验收；该状态、动作中断、音效和回档由主会话实机抽查与回归覆盖。背景整体仍未全面分层，远处树冠/山体的全部动态遮挡不是本次自动得到的能力。
