状态：0.14.0 八个日期包已正式注册，共享自动化、构建与下述浏览器抽检完成，本轮集成本地验收完成，已普通推送至用户指定 GitHub 仓库 main 分支。本文不把作者自检或无图形的 Canvas 替身测试当作真人试玩，也不把抽检扩大为全量人工遍历。

## 玩家能体验什么

八张原有室外地图各增加一张可进入、原路返回的独立子图，每张至少两块可辨识区域。室内使用独立地面、家具碰撞、交互站位与小地图探索阴影。原主线四谜题、口令、今日小事、危险与印章结构保持；自由探索不影响能否通关。

点击原画真门后，人物实际导航至门前才切场景。目标卡展开后的“自由探索 · 前往……”同样执行行走，不是快捷传送。室内点原门或“走到出口，返回大地图”可离开。磨坊、观瀑亭与原主线同门时明确选择进入或调查；DAY04 必须先解开 `lily-path`，其他新入口初始可达。

背包展示归档物；日志列本日发现/环境证据、地方成就与八日收藏计数。没有新增长驻任务大厅或成就页。动物为真实透明精灵，在指定可走地面巡游，接近时停下，点击有声音/文字反馈；不是只显示一个名字或提示框。

## 机制、状态与存档

- `requires` 表达本地工具/知识前置；缺项时说明原因而不写完成标记。`sequence` 记录对世界内实物的调查顺序，确认错误可以重来，不消耗工具或生命。
- 修伞、广播旋钮、幼苗、记录纸与菌床有相应状态图；其它活动使用实物观察、抄录、拍摄、借用或取一份语义，不伪称未变化的背景实物已被搬走。
- 稳定发现 ID 只结算一次；已发现可复读，不刷奖励。地方成就按已有标记推导，没有额外经验等级或抗灾数值。
- 继续使用浏览器 v2 存档，新增 `discoveries`、`visitedRooms`、`roomExplored`。旧主线进度、提示和设置不因扩展被清空。
- 正常返回恢复室外进门位置。在室内保存后刷新，恢复到室外门前；室内发现、访问与阴影记录保留。不会把房内坐标误当室外检查点。
- 重玩一天保留自由探索记录；主动“删除存档”仍清空全部记录。不同浏览器源各自持有存档，GitHub 不保存玩家进度。
- 室内没有新增致命危险，室外危险在室内不继续推进。室内自由活动不会清除室外威胁或改变原主线解法。
