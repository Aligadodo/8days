# v0.16 可再生采集内容审查与扩充

## 范围与原则

本次独立内容任务负责 `life/day03.ts`—`day08.ts`。已逐张查看六日室外原图及对应室内背景，共 12 张 1672×941 原画；不生成、改画任何位图，不修改碰撞、主线、原有发现或成就要求。DAY01–02 的四处增补由主任务负责。

以已有物件为入口增加 **11 个可再采集来源**：7 个新增生活节点、2 个观察节点升级采集、2 个一次性公共容器升级为轮次补给。不是新增 11 个箱子，也不是所有原画装饰均可领取。共享发现保持原 ID、轮廓、站位及原收藏/拍照逻辑；没有给带前置条件的发现接上无条件领奖通道。

只收少量自然脱落物、园丁允许的修剪余料、明确向访客开放的纸料与矿物分样。蜂蜜、活根、桥索、承重石、整株植物、私人信件和失物不作为产出；现有观察描述保留在交互说明中。冷却按当前共享运行时的活跃游戏时间计算，暂停/离线不产生补给。

## DAY06 室内为何不凑第 3 处

原山舍图的实体是干巾/蓝布、共用热炉及火钳、雨披与沥水靴、地图/登记本、小桌凳和高墙架盆栽。两叠布已各有独立再生份额，盘边还有一次备用擦靴布；再把同一布堆分成热点只是重复堆数。炉灰仍热、雨披/靴属于旅人，高墙架草盆无法在现有地面直接够到。保留 6 个节点（1 容器、2 再生、3 观察），不新造布堆、不侵占私物、不为了采集改墙或搭隐形路径。

## 公共容器升级与旧存档

`d05-life-desk-right-drawer` 和 `d08-life-right-tin` 是明确的 v0.16 补给政策升级，不是刷新后重开旧箱。两者没有 `afterArt`，不产生旧开盖贴片突变。

运行时任务已为这两个 ID 增加迁移：旧存档若已持有一次容器领取标记且没有采集轮次，保留原 `containers` 历史和 `container:ID` 经济凭证，同时建立 `readyAt = activeSeconds + 420`、`cycle = 0`。升级不会立即加物品/金币；完整冷却后才领取第一次新补给。已有 `gathered` 的存档沿用既有时间和轮次，再刷新不会重置冷却或重复领第 0 轮。

两个观察→采集节点保留 ID 与观察叙述，不删除任何原发现，也不改变地方成就条件。
