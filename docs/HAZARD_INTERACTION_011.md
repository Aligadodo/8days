# 危险与失败交互规范 · 0.11

状态：招牌完整样板与全关卡公共流程已实现；各灾害的专属美术、真实地形演变仍需要分批细化。本文覆盖旧版“周期命中直接弹窗”的实现说明。

## 1. 设计目标

玩家应能在不看死亡解释时回答：“刚才哪里不对劲？什么东西发生了变化？我为什么被击中？下次往哪里走？”

死亡不是通知，而是世界里发生的一件事。提示框只是最后的复盘，不承担补画事故的责任。反应难点来自及时观察、选择安全落脚点，不来自隐藏判定、抢在弹窗前点击或猜程序周期。

## 2. 招牌垂直样板（已实现）

地点：DAY 01 咖啡店沿街人行道。地面落点中心 `(870, 340)`，脚底判定椭圆边界矩形 `(814, 313, 112, 54)`，碰撞带 5 像素容差。招牌从落点上方约 110 世界像素处落下；画面有实体木框、咖啡图案、两处吊点和金属支架。背景原有店铺门头不作为落物。

| 相对时间 | 玩家看到 / 听到 | 控制与判定 |
| --- | --- | --- |
| 靠近前 | 挂在店前的招牌、支架与吊链 | 正常探索；未进入镜头或仍在重来保护期，不启动事故 |
| 0–1.50 秒 | 招牌逐渐摇晃，尘屑落下，地面出现自然投影；吱呀、摩擦声与可选声音字幕 | 保留鼠标 / 键盘撤离；不致死，不自动取消玩家正在离开的路径 |
| 1.50–1.92 秒 | 挂钩断裂，短促“咔”声，招牌加速下落，投影加深 | 仍可撤离；招牌尚未落地时不能提前判死 |
| 1.92 秒 | 木板落地、碎屑扬起、低沉撞击和小碎块声 | 仅此刻检查落点；离开范围则正常继续，不进入死亡流程 |
| 命中后 0–0.28 秒 | 主角失去支撑、倒下；水 / 软泥改为下沉表现 | 锁定移动与交互；只结算一次死亡，不弹窗 |
| 命中后 0.28–0.85 秒 | 主角渐隐，场景边缘柔和变暗 | 隐去常驻 HUD，不闪白、不展示伤口 |
| 命中后 0.58–约 2.08 秒 | 带黄色围巾的小灵魂升起、渐淡，轻柔上行音 | 仍未显示重来按钮；保留一次短暂的情绪停顿 |
| 命中后 2.45 秒 | 显示实际游戏时间、事故原因、前兆回顾、下次可执行动作与重来按钮 | 键盘焦点落在重来按钮，可直接 Enter 重来 |

左右两条已验证的撤离线：`(870,340) → (755,340)` 与 `(870,340) → (990,350)`，均是可走的直线。正常鼠标导航实测使用右侧 `(1010,355)`，能在预警内撤离。

### 躲过之后不是“什么也没发生”

- 招牌仍然落地、发声、扬尘，保留断裂吊链和开裂木板。
- 只有实际进入过威胁范围、随后离开的玩家会收到一次“及时离开”的轻提示；远处围观不刷奖励。
- 残骸无隐藏持续伤害，不制造新的不可走墙；按脚底深度排序，不永远盖在主角上方。
- 同一次探索中招牌只坠落一次。死亡重来 / 重载关卡会重建物理状态，表示重新尝试这段旅程；不会在游玩中每隔 9 秒凭空修复。

## 3. 全关卡复用的事件流程（已接入 16 个危险）

`静止 → 预兆 → 释放 / 蓄势 → 实际发生 → 余波 → 消退或留下结果`

- 每个危险以自己的场景时钟推进，不再使用全局时间取模直接决定伤害。
- 靠近并且事件中心在镜头安全范围内，才允许首次启动；招牌使用扩展落点邻域，其他危险当前使用 215 世界像素邻近范围。
- 招牌预警固定 1.5 秒；其他危险预警为 `max(1.5, activeFrom - warningFrom)`，保留原先更宽裕的反应时间。
- 固体落物有 0.42 秒下落与一次落地判定；其他危险有 0.5 秒蓄势、持续生效期、1 秒消退，再经过安静期才能重来。
- 水、电、烟汽等持续危险仍按显示区域判定；列车进一步按实际移动的车身位置判定，不在车尚未进入时杀死整段轨道的人。
- 寻路继续避免正在发生的危险，必要时在边缘等待并保留目的地。它不代替玩家主动离开预警范围。
- 角色死亡统一经过动作反馈、渐隐、灵魂和复盘。重复调用不能重复记死亡、重复开弹窗或提前跳过动画。
- 主线、支线、探索、提示和最近主线检查点保留；重来重置危险事件，并提供 6 秒不启动新事故的保护期。解决机关永久移除的危险仍由存档中的解谜结果禁用。

## 4. 各类危险的表现与边界

| 关卡 / 危险 | 本轮已实现 | 还需专属制作 |
| --- | --- | --- |
| 雨城：招牌 | 实体挂件、摇晃落灰、断链下落、撞击残骸、命中 / 落空全分支 | 更高细节木框材质、不同受击姿态 |
| 雨城：带电积水 | 微弱电弧预警、强电弧、短促电流声、解开雨篦后禁用 | 与可见破损电缆连接，不把风险表现为孤立电圈 |
| 办公室：吊顶 / 浓烟 | 落块、尘屑 / 烟层变浓与消散、压力声 | 真实天花吊点、烟源与通风口变化 |
| 花谷：强风 / 枯枝 | 定向风线 / 木枝掉落与残留 | 花草一致伏倒、树冠断口；首次非致命练习 |
| 瀑布：急流 / 水帘落石 | 水纹加速、冲刷色层、落石接触；阀门可禁用急流 | 真实水位线、上游涌水推进、石块前景遮挡 |
| 河湾：软泥 / 涨水 | 泥纹塌陷色层、水纹推进；主角下沉后灵魂离开 | 逐步陷入的可挣脱窗口、岸边水位参照物 |
| 山谷：碎石 / 山洪 | 碎块落下、扬尘 / 水流事件、不同音色 | 泥石流有实体前沿、高地避难点与冲刷后的地形 |
| 雪站：冰锥 / 调车 | 冰块下落、汽笛与灯光、小车身通过，接触随车移动 | 檐口冰锥独立资产、与背景轨道角度完全对齐的列车 |
| 地下河：蒸汽 / 水晶崩落 | 压力预兆、汽柱 / 晶块下落、余波 | 裂隙压力计、独立晶簇断裂与局部照明 |

以上是程序化场景效果，不是完整灾害物理模拟。16 个危险都接入共同流程，不等于 16 段定制事故演出都达到招牌样板的细节。旧背景中没有拆分的吊顶、树冠等不能被描述成已经真正损坏。

## 5. 暂停、音频和可访问性

- 打开背包 / 谜题时冻结事件；隐藏网页时冻结危险和灵魂时间，同时暂停音频。恢复后不补算离开时长。
- 关键预警有实际动画，不依赖声音字幕；开启“加强危险轮廓”时才显示完整边界与预警剩余秒数。
- “减少动态效果”取消招牌摇晃、身体旋倒和灵魂位移，保留必要的落物位移、静态灵魂与淡入淡出；不会移除重要阶段或缩短反应时间。
- 事故期间临时降低音乐与环境声，效果声保留。音量偏好不被修改，重来时恢复。
- 木质摩擦、断裂、撞击碎块、水流、电流、压力、列车和灵魂使用不同事件 ID。当前为 Web Audio 合成音色，不称为拟真录音。
- 快捷栏、背包和任务卡在死亡演出 / 复盘期间不可激活；不允许另一个面板打断流程或产生重复结算。

## 6. 将同一标准扩展到所有交互（下一轮，尚未全部实现）

每个交互先写五件事：**意图可见 → 靠近与动作 → 世界变化 → 成败反馈 → 再次查看**。

| 交互 | 应发生的完整过程 | 不应只做 |
| --- | --- | --- |
| 排水篦 | 草叶吸向堵口 → 俯身清理 → 杂物进入背包 → 水位回落、电弧消失 → 干燥路面可再次观察 | 答对后增加数字 |
| 三级水阀 | 拉动阻力 → 手轮转动与金属声 → 水槽顺序改变 → 水轮稳定 → 踏石通路出现 | 面板文字声称水流变化 |
| 救猫 | 箱中探头与小幅退缩 → 蹲下伸手 → 猫走到避雨处 → 叫声 / 蹭腿 → 再次接近有回应 | “你救了猫”的单一消息 |
| 获取道具 | 手伸向物件 → 原处缺失或容器变空 → 一次拾取音 → 快捷格短亮 → 日志记录来源 | 突然出现一格图标 |
| 无效尝试 | 物件的阻力 / 缺件 / 未供能状态直接响应 → 一句指出现场原因 → 保留玩家输入 | 通用“错误”音加扣分 |
| 通关 | 机关真实开启 → 主角走过门槛 → 看见今天留下的变化 → 停留片刻 → 印章结算 | 输入口令立即跳结算 |

实施顺序：先完成“排水篦改变环境”与“水阀改变水路”两条因果链，再扩展救猫后续与终点演出。暂不加入额外任务中心、死亡统计大厅、QTE 或战斗血条。

## 7. 制作与验收入口

- 配置：`src/campaign/levels.ts` 的危险 `kind`、落点、前兆和复盘文案。
- 状态 / 时间 / 判定：`src/campaign/hazardDirector.ts`。
- 场景演出：`src/campaign/hazardRendering.ts`；旅人倒下与死亡控制由 `CampaignGame.ts` 接入。
- 声音：`src/audio/AudioManager.ts`；复盘 UI：`src/main.ts`。
- 自动测试：`tests/hazards.test.mjs` 与 `tests/campaign.test.mjs`。
- 浏览器评审：开发服务器加 `?debug=1`，点击“评审招牌事故”。使用单独端口以免覆盖正式玩家存档；此按钮会重开 DAY 01 测试进度，生产构建不显示。
- 核验四条分支：原地被击中、预警后撤离、落地后返回、菜单 / 后台暂停。静音和减少动态效果也必须能读懂前兆。
- 后续必须安排真实新玩家无说明试玩，确认落灰辨识度与反应时间。自动测试不代替听感评审、手柄测试或八关逐一的无说明通关。
