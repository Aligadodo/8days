# 0.16 · 找得到、收得到、用得上

验收日期：2026-09-08。版本：`0.16.0`。本轮在既有背包、经济与探索系统上补齐入口、发现和用途，没有另建一套货币或修改主线通关条件。

## 玩家现在怎样操作

- 右上角 **背包 / 商店** 打开口袋菜单，顶栏直接切换 **背包、商店、伙伴、成就、更多**。
- 背包顶部 **附近可收集 → 前往**：说明产出、可打开/可采集状态及沿路距离，角色正常走近再操作。也可以点 **找一处**。
- 选中背包物资可查看持有量、出售价格、数量及消耗效果；商店购买补给，伙伴页查看领养价格、差额和同行队伍。
- 底部第五格 **成就** 可直接打开条件、当前进度和完成筛选。页面展示4项跨日生活成就及本日2项地方成就，地方成就仍保留在原发现记录中。
- **更多** 保留任务线索与收藏、生活日志、存档、设置，以及 **再看生活玩法引导**。首次引导可关闭，关闭状态独立保存；升级旧存档也能看到它，不删除进度。

资源仅在鼠标悬停实物时显示短动作说明和细光边。地图不铺常驻光圈，不把观察家具误称为必有掉落的箱子。

## 发现、导航和存档约束

- 推荐最多3个当前场景中已知、前置满足、准确操作位可达的资源。附近视线仍被墙隔开的对象不算已知；未知点不泄漏名称/坐标。
- “尚有物资”是当前场景尚有库存的总数；“可带路”是目前实际可推荐数，两者不混称。无推荐时说明探索、冷却或换场景的原因。
- 引导沿正常路线移动，不传送，不替玩家穿家具或跨谜题。路线开始、行进和采集蓄势阶段均复核危险；新预警挡路时停止，不能在危险中隔空领奖。
- 路线按场景、位置分区、已知状态、前置、导航修订和危险缓存，避免每帧重复寻路；冷却文字继续按活跃时间更新。暂停和离线不会生产物资。
- DAY05公共纸抽屉、DAY08分样罐由一次性容器升级为再生来源：旧领取凭证保留，首次升级安排完整420秒冷却，不立即多送一份；再次刷新不重置冷却。
- 一次性箱柜、原主线线索、金币、伙伴与原成就存档规则均保留；消耗品没有免伤、复活或自动搜刮效果。

## 后续边界
