# 八日旅程 0.8 实现规格

## 版本目标

0.8 将单关验证版升级为可从头到尾推进的八关战役。每关必须具备独立的场景气质、四种主线推理、两件可选小事、两种公平危险、符号口令结算和一句生活落点。当前图形与声音仍为程序化制作，但内容流程不再使用占位关卡。

## 统一关卡闭环

1. 战役页说明当天情境与目的，只解锁已到达的日子。
2. 常驻任务卡指出当前主线、为什么要做以及地图光边规则。
3. 玩家点击地面移动，点击金色物件自动靠近；绿色物件是可选小事，装饰没有光边。
4. 谜题先展示两条现场证据，再要求顺序、选择、规律或数字操作。
5. 错误反馈解释冲突的规则，不只显示“错误”；玩家可逐层打开 H1—H3 提示。
6. 每个谜题揭示一个“符号＝数字”关系并写入日志。
7. 终点给出新的符号顺序，玩家必须查日志重组四位口令。
8. 结算记录主线、支线、重来和提示数量，授予印章并解锁下一天。

## 引导强度

- H0 永久在线：当前任务、目的、金色目标、现场证据。
- H1 注意点：指出应该优先观察的对象，不给答案。
- H2 关系提示：指出证据之间要使用的排序、排除或计算关系。
- H3 明确动作：给出可直接执行的步骤，避免玩家永久卡关。
- 当前目标在视野外时显示边缘方向箭头；进入视野后由呼吸金框接管。
- 已完成目标改为绿色和符号数字，不再与未完成目标竞争注意力。
- 危险在生效前以区域变化、文字、声音字幕和轮廓中的至少两种方式预警。

## 技术与存档

- `levels.ts` 是八关内容数据源，启动时自动校验关卡数量、谜题数量、提示数量、依赖和口令推导。
- `CampaignGame.ts` 使用 `1600×900` 世界、`960×540` 逻辑视野和 2 倍 Canvas 缓冲。
- 静态建筑由 A* 绕行；动态危险不进入寻路代价，仍要求玩家观察并取消路线。
- 存档键为 `one-more-day:campaign:v2`，保存解锁、完成、印章、谜题、支线、提示和死亡次数。
- 死亡后保留已解谜题与日志关系，角色回到关卡起点。
- 全屏使用 Fullscreen API；普通页面保持 16:9，不通过非等比拉伸填满窗口。

## 当前发布边界

0.8 是“八关内容正式化、系统仍为网页制作版”：所有关卡可玩、可存档、可结算，但角色动画、瓦片精灵、配乐和音效仍是程序化或合成资源。进入公开商业发布前，还需要正式资产替换、移动端横屏适配、手柄支持、存档迁移测试、性能测试以及 5—10 名无说明玩家的逐关数据。
