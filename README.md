# 今天，也要好好活着

一款明亮、可爱但带有生存主题的 Q 版像素探索游戏。玩家在生活、工作、出行和旅行场景中观察环境、使用道具、解开线索，并在一次次失败后理解危险规律。

## 当前版本

`0.8.0`：八日旅程可玩内容版。

- 八个可顺序解锁的正式关卡：城市暴雨、深夜写字楼、花谷、瀑布、秋日河湾、骤雨山谷、暴雪车站和发光地下河
- 每关 4 个主线谜题、2 件支线小事、2 类有环境预兆的致命危险和 1 次符号口令重组
- 顺序操作、条件选择、规律补全、数字逻辑四套可复用谜题交互
- H0 现场证据、H1 注意点、H2 关系提示、H3 明确动作的分层提示体系
- 常驻主目标、进度、原因说明、地图金色光边、离屏箭头与点击寻路组成的统一引导
- 鼠标点击地面移动、点击目标自动靠近调查；右键取消，WASD / 方向键与 E 调查作为备用输入
- 960×540 逻辑视野、2 倍内部缓冲、整数像素绘制，并保持 16:9 页面比例
- 原生浏览器全屏与响应式布局
- 折叠式道具、日志、存档和设置菜单，不增加常驻功能页面
- 谜题错误原因、局部正确反馈、危险字幕、死亡知识卡与保留线索重来
- 四路音量、重要声音字幕、单声道和减少动态效果
- 八枚印章组成最终句子“好好生活，明天再见”
- 浏览器本地自动存档与关卡进度解锁

## 本地运行

```bash
npm install
npm run dev
```

正式构建：

```bash
npm run build
```

## 目录

- `src/campaign/levels.ts`：八关内容、谜题、危险、地图与口令数据
- `src/campaign/CampaignGame.ts`：战役地图、点击寻路、交互、危险、存档与渲染引擎
- `src/main.ts`：战役、谜题、日志、结算和设置界面
- `docs/`：设计、关卡、艺术方向、路线图和决策记录
- `docs/REFERENCE_ANALYSIS.md`：参考游戏的操作与地图原则分析
- `docs/CONTENT_SYSTEM_PLAN.md`：可复用元素库、任务成就和地图深化计划
- `docs/PUZZLE_AUDIO_ITERATION_PLAN.md`：专业解谜框架、花谷 0.4 谜题链、音频语言与实施验收
- `docs/LEVEL_AUTHORING_TEMPLATE.md`：后续每一关复用的谜题、危险、音频和试玩策划卡
- `docs/CAMPAIGN_08_SPEC.md`：0.8 八关实现范围、内容矩阵、引导和验收口径
- `design/concept-art/`：已确认和探索中的概念原画

设计文档与实现状态必须一起更新。原画用于方向校准，不应直接视为最终可发布的地图或精灵素材。
