# 今天，也要好好活着

一款明亮、可爱但带有生存主题的 Q 版像素探索游戏。玩家在生活、工作、出行和旅行场景中观察环境、使用道具、解开线索，并在一次次失败后理解危险规律。

## 当前版本

`0.14.0`：八日旅程 · 门后的生活（八包已集成，本轮本地验收完成）。

在原有八张室外地图之外，每天新增 **1 张可进入、可原路返回的多区室内子地图**。这是 8 张新增可玩地图，不是把原图放大，也不代表所有建筑或每一间房都已开放。

- 24 个室外发现 + 75 个室内交互，共 99 个新增发现节点；含 38 项去重归档奖励、14 处打卡、16 项地方成就、9 只可见巡游动物（猫、狗、鼠）。奖励和打卡等是节点的属性，不能重复相加为互动总数。
- 各日可选玩法涵盖修伞、收音机维护、幼苗照料、水声记录、果酱试做顺序、避雨路线判断、失物核对与菌床导水；不替代主线，也不增加通关的收藏门槛。
- 点击真实门即可自动走近。花谷磨坊与瀑布观瀑亭的门同时承载主线，走近后选择“进入室内”或“调查门旁物件”。瀑布观测所须先打通主线踏石通路，其余新入口初始可达。
- 室内有独立地板、家具碰撞、交互站位与探索小地图；收藏、发现、地方成就及八日收藏进度仍放在现有背包/日志，不新增常驻页面。
- 动物在真实地面巡游，靠近互动时停下；物件仅悬停细描边。共享修复系统支持按前置条件改变局部场景图，顺序类支线通过点击世界中的实物验证。
- 保持 v2 本地存档：重玩当天仍保留新增收藏、房间访问与探索记忆。在室内保存后刷新，会回到室外门前，房内发现不丢失；“删除存档”仍会清除全部进度。

先试一间房：进入当天地图 → 点击左上目标展开说明 → 点击“自由探索 · 前往……”；角色会实际走到门前，不会传送。室内用原门或同一说明中的返回按钮走到出口。按背包中的“日志”查看支线证据和地方成就。

逐日玩法、素材与检测边界见 [0.14 发布说明](docs/EXPLORATION_014_RELEASE.md)、[统一制作标准](docs/EXPLORATION_014_STANDARD.md)及 [DAY01–08 报告目录](docs/exploration-014/)。八包已正式注册；112 项自动化测试、原地图与探索审计各 8/8、正式构建通过。隔离浏览器逐一目视八间正式子场景，核验背景、出生点、小地图与动物合成；DAY01 真门导航/工具收藏刷新、DAY02 全屏、DAY03 原门返回/双用门暂停焦点/重进与日志显示通过。本轮按该范围完成本地验收：DAY04 双用门仅有逻辑回归，不声称 99 节点均已手动遍历或完成真人试玩。

## 本地运行

需要 Node.js `^20.19.0` 或 `>=22.12.0`（符合当前 Vite 依赖要求）。首次安装推荐使用锁文件：

```bash
npm ci
npm run dev
```

正式构建：

```bash
npm run build
npm run preview
```

`npm test` 运行自动化回归。QA 请使用独立源（例如 `npm run dev -- --host 127.0.0.1 --port 5174 --strictPort`）；`localhost`、`127.0.0.1` 和不同端口的浏览器存储互相独立，勿在玩家实际地址上清档做测试。

源码目标仓库：[Aligadodo/8days](https://github.com/Aligadodo/8days)。Git 同步不等于网站部署；运行时不需要 GitHub 密钥或第三方 API 密钥。关联与推送状态以发布验收记录为准。
