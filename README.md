# 今天，也要好好活着

一款明亮、可爱但带有生存主题的 Q 版像素探索游戏。玩家在生活、工作、出行和旅行场景中观察环境、使用道具、解开线索，并在一次次失败后理解危险规律。

## 当前版本

`0.10.0`：八日旅程 · 探索与交互整修。

- 八个顺序解锁关卡，32 个主线谜题、16 件可选小事、16 个周期危险。
- 统一朝向的主角动作表；实际步长驱动动画、稳定转向、平滑启停。
- 鼠标直线优先、八方向绕障、自动走近物件、右键取消；WASD / 方向键与 E 作为备用。
- 八关独立地形区域；动态危险无路可绕时在边缘等待并继续原路线。
- 可见的小猫、人物与道具；只在鼠标悬停时显示细轮廓，不再使用常驻光圈和亮方框。
- 带探索阴影、当前位置/方向、已发现物件和按需目标定位的可折叠小地图。
- 瀑布踏石谜题会实际出现过河石路并开放通行。
- 排序题完整提交、稳定洗牌、共享分层提示；终点可以直接翻看记忆卡。
- 主线检查点与探索/提示/小事持久化；八枚印章正确组成“好好生活，明天再见”。
- 真全屏、适应长宽比的相机、竖屏地图；折叠菜单与五格口袋栏。
- 4 张新图集的原图、完整提示词与切片规则均随项目保存。

本轮逐项设计审视、已实现/未实现边界和下一轮建议见 [体验审视](docs/EXPERIENCE_AUDIT_010.md)。背景尚未完全分层，部分谜题仍是面板推理；不把它们描述为已全部空间化的成品。

## 本地运行

```bash
npm install
npm run dev
```

正式构建：

```bash
npm run build
```

## 目录

- `src/campaign/levels.ts`：八关内容、谜题、危险、地图与口令数据
- `src/campaign/CampaignGame.ts`：战役地图、点击寻路、交互、危险、存档与渲染引擎
- `src/main.ts`：战役、谜题、日志、结算和设置界面
- `docs/`：设计、关卡、艺术方向、路线图和决策记录
- `docs/REFERENCE_ANALYSIS.md`：参考游戏的操作与地图原则分析
- `docs/CONTENT_SYSTEM_PLAN.md`：可复用元素库、任务成就和地图深化计划
- `docs/PUZZLE_AUDIO_ITERATION_PLAN.md`：专业解谜框架、花谷 0.4 谜题链、音频语言与实施验收
- `docs/LEVEL_AUTHORING_TEMPLATE.md`：后续每一关复用的谜题、危险、音频和试玩策划卡
- `docs/CAMPAIGN_08_SPEC.md`：0.8 八关实现范围、内容矩阵、引导和验收口径
- `docs/ASSET_GENERATION.md`：0.9 环境与 0.9.1 角色动作资产的生成提示、路径和使用边界
- `docs/CHARACTER_MOTION.md`：角色方向、步幅、缓动、落脚反馈与动作扩展规范
- `docs/AI_PLAYER_REVIEW_01.md`：三类 AI 玩家评审、修正项和后续优先级
- `design/concept-art/`：已确认和探索中的概念原画
- `public/assets/maps/`：0.9 八张可玩关卡环境绘制

设计文档与实现状态必须一起更新。当前资产已达到内部展示与玩法验证标准；商业发布前仍需补齐来源登记、性能压缩，以及左右侧身和更多情绪动作。
